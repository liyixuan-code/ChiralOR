# Deployment Schema B

The ChiralOR web interface uses a deployment-specific feature-generation implementation (Schema B). It is distinct from **Publication Schema A**, which underlies all performance, calibration, ablation, and SHAP-based results reported in the manuscript.

The publication metrics must **not** be assigned to the Schema B web model. Deployment model binaries and Schema B feature matrices are intentionally excluded from this publication reproducibility repository.

See `../figure_source_data/supporting_information/` and the manuscript Supporting Information for the feature-block comparison between the two schemas.
