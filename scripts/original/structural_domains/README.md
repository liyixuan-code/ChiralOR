# Structural-domain workflow (R01–R41)

`generate_stereo_invariant_rules.py` is the recovered original stereochemistry-invariant rule-generation workflow. The public release excludes the licensed molecular structures used as its inputs.

The final publication source table is `../../../results/structural_domains/structural_rule_table_final_5204.csv` (duplicated under `../../../figure_source_data/supporting_information/structural_rule_table.csv` for figure/SI source-data use). It contains 41 mutually exclusive classes over 5,204 observations, with the final class counts and empirical directional consistency values used in the Supporting Information.

OR sign is not an input to the class definitions. OR+/OR− counts are post-classification descriptive summaries.
