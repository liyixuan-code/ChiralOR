# Software Environment

## Publication reproducibility environment

Confirmed versions recorded for the final publication/scaffold rerun:

- Python 3.11.9
- NumPy 2.4.6
- pandas 3.0.5
- scikit-learn 1.9.0
- CatBoost 1.2.10
- RDKit 2026.03.5

Additional packages required by public scripts:

- pyarrow >= 10.0.0 (for parquet support)
- scipy >= 1.10.0 (for statistical functions)

For historical analysis packages (SHAP, XGBoost, LightGBM, matplotlib, seaborn) used in recovered original scripts: VERSION_NOT_RECOVERED for exact historical versions.

The public environment specification is intended to support execution of the released reproduction scripts and recovered analysis code. It is not asserted to reconstruct every historical software environment used during model development.
